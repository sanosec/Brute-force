## Usage

```
python hashforce.py -w <wordlist> [options]
```

### Arguments

| Argument | Short | Required | Default | Description |
|---|---|---|---|---|
| `--wordlist` | `-w` | Yes | — | Target the location of wordlist |
|`--hash` | `-s` | Yes | — | Hash you want discover |
|`--detect` | `-d` | Yes | — | Discovery the hash type |
|`--type` | `-t` | Yes | — | Type of hash you want bruteforce (optional) |
